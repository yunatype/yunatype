# Yunatype

必要なフォントを、使いたいときだけ素早く有効化（動的アクティベーション）。数万件のフォントを OS にインストールせずに管理できる、Windows / macOS 対応の無料フォントマネージャーです。

システムを重くすることなく、Photoshop や Illustrator のフォント一覧もすっきり。探して、見比べて、そのまま制作ソフトのキャンバスへドロップ。フォント選びのストレスを減らし、デザインの試行錯誤をより軽快にします。

**対応**: Windows 10 / 11（64 ビット）、macOS 11（Big Sur）以降（Apple Silicon・Intel の両対応）

**English**: [README.en.md](README.en.md)

---

## 🚀 はじめる

1. [Releases](https://github.com/yunatype/yunatype/releases/latest) からインストーラー（Windows は `Yunatype_<バージョン>_x64-setup.exe`、macOS は `.dmg`）をダウンロードして、インストールします。
2. Yunatype を起動して、**環境設定 ＞ フォントフォルダ**でフォントを置いているフォルダ（ローカル、NAS、外付けディスク）を追加します。取り込みが終わると一覧に表示されます。
3. フォントを探して **Enter** で有効化します。制作ソフトのドキュメントへドラッグ＆ドロップすることもできます。

インストールの途中で警告が出たときは、[インストールの詳細](#-インストールの詳細)を見てください。

## ✨ 主な機能

- **インストール不要の動的アクティベーション**: 起動中だけ、必要なフォントをシステム全体に即時ロードします。アプリの終了時や異常終了からの復帰時には、有効化したフォントを自動で回収します。
- **高速なライブラリ管理**: ファミリー単位の表示、ウェイト別の一覧、高速な検索。数万件の一覧を、キーの押しっぱなしでも止まらずにスクロールできます。
- **NAS / LAN 上のフォルダに対応**: フォルダを並列に探索し、進捗（件数・取り込み中のフォント名）を表示します。キャンセルもできます。設定からフォルダを外すと、配下のフォントもライブラリから外れます（フォントのファイル本体は削除しません）。
- **クイックルック（Space）とグリフマップ**: 大きな書体見本、ファミリー全ウェイト、詳細メタデータ、収録文字の一覧。プレビューは、フォントの実際の見え方をそのまま表示します。
- **フォントの比較**: 一覧で複数選んで Space（4 件まで）。クイックルックを複数のフォントで横に並べます。見本の文字・サイズ・タブは全フォントに同時に効きます。
- **診断**: 有効にしたのに Photoshop などに出ないフォントの原因を探ります（ファイルの状態、Windows の認識、同名フォントの重複）。
- **制作ソフトとの連携**: Photoshop・Illustrator・Figma・Affinity のドキュメントで使われているフォントを検知し、自動で有効化します。ドキュメントを閉じると、そのフォントだけを自動で解除します。
- **制作ソフトにドロップして、文字を置く**: 選んだフォントを制作ソフトのドキュメントへドラッグ＆ドロップすると、一覧に出ている見本の文字をそのフォントで置きます。複数選んでドロップすると、縦に並べて置きます（最大 10 個）。
- **検索**: 名前・PostScript 名・英語名・メーカー・デザイナー・タグなどで探せます。候補から選んだメーカーやスタイルは、その項目だけで絞り込みます。
- **Google Fonts を同じ一覧に混ぜられます**（任意。既定はオフ）: 環境設定でオンにすると、Google Fonts の名簿のフォントが手持ちのフォントと同じ一覧に並びます。ダウンロードする前に見本を見られます。有効にした（Enter）ときに、そのファミリーだけをダウンロードします。手持ちに同じフォントがあれば、手持ちが優先されます。
- **言語フィルター**: 日本語、簡体字、韓国語、ラテン文字、キリル文字、ギリシャ文字などでフォントを絞り込めます（複数選択できます）。
- **14 言語の画面と 5 つのテーマ**: 日本語 / English / 简体中文 / 繁體中文 / 한국어 / Deutsch / Français / Español / Italiano / Português / Nederlands / Dansk / Polski / Русский。インストーラー、Adobe の拡張機能、Figma のプラグイン、タスクトレイのメニューも各言語に対応しています。見本の例文も各言語のものを選べます。

## ⌨️ 基本的な使い方

Yunatype は、マウス操作はもちろん、キーボード中心の高速なワークフローにも対応しています。

| やりたいこと | 操作 |
|---|---|
| 🔎 フォントを探す | 上の検索窓に、フォント名・PostScript 名・メーカーなどを入力（`/` または Ctrl+F で移動）。Enter か、候補を選ぶと確定 |
| 👀 大きな見本を見る（クイックルック） | フォントを選んで **Space**。↑↓ で前後のフォント、←→ でウェイトの切り替え |
| ✨ フォントを有効化する | 一覧で **Enter**（もう一度押すと解除） |
| ⚖️ 複数フォントを見比べる | 複数選んで **Space**（4 件まで）。または **M** で比較に追加して **Shift+M** |
| 🎨 制作ソフトに文字を置く | 選んだフォントを Photoshop などのドキュメントへドラッグ＆ドロップ |

ショートカットの一覧は **?** キーで見られます。

## 🎨 制作ソフトとの連携

| アプリ | 最初の設定 | ドキュメントを開くと自動で有効化 | ドロップで文字を置く |
|---|---|---|---|
| Photoshop（Windows） | 不要（インストーラーが拡張機能を入れます） | ○ | ○ |
| Photoshop（macOS） | オートメーションの許可（初回に 1 回） | ○ | ○ |
| Illustrator（Windows） | 不要（インストーラーが拡張機能を入れます） | ○ | ○ |
| Illustrator（macOS） | 拡張機能を入れる（初回に 1 回） | ○ | ○ |
| Figma Desktop | プラグインを登録する（初回に 1 回） | ○（プラグインを開いている間） | ○（プラグインを開いている間） |
| Affinity（3.2 以降） | MCP サーバーを有効にする（初回に 1 回） | ○ | ○ |

### 制作ソフトにドロップして、文字を置く
一覧で選んだフォントを上のアプリのドキュメントへドラッグ＆ドロップすると、ドロップした場所に、一覧に出ている見本の文字をそのフォントで置きます。まだ有効になっていないフォントは自動で有効にします。フォントが反映されるまで、マウスカーソルが待ちの表示になります。取り消し（Ctrl+Z / ⌘+Z）で置いた文字を消せます。

### Photoshop / Illustrator
ドキュメントを開くと、使われているフォントを検知して自動で有効化します（ドキュメントを閉じると、そのフォントだけを自動で解除します）。

- Windows の Photoshop・Illustrator: インストーラーが拡張機能を自動で入れます。
- macOS の Photoshop: 拡張機能は要りません。初めて連携するときに、**システム設定 ＞ プライバシーとセキュリティ ＞ オートメーション**で Yunatype から Adobe Photoshop への操作を許可してください。
- macOS の Illustrator: 最初に 1 回、Yunatype の**環境設定 ＞ 連携**で「拡張機能を再インストール / 最新化」を押して拡張機能を入れます。
- 拡張機能を入れたアプリは、パネルを開かなくても裏で動きます。つながっているかを見たいときは、メニューの「**ウィンドウ ＞ エクステンション ＞ Yunatype**」を開きます。

### Figma
Figma Desktop のプラグイン「Yunatype」を使います。**最初に 1 回だけ**次の設定をします。

1. Yunatype の**環境設定 ＞ 連携**を開き、「Figma Desktop プラグイン連携」の欄で**「プラグインのフォルダを開く」**を押します（`manifest.json` が選択された状態で開きます）。
2. Figma Desktop で **Plugins ＞ Development ＞ Import plugin from manifest...** を選び、1 のフォルダの `manifest.json` を選びます（欄の「manifest.json のパスをコピー」でパスを貼り付けることもできます）。
3. 環境設定の**「外部連携 API トークン」**の「コピー」を押し、Figma のプラグインのトークンの入力欄に貼り付けて保存します。

使い方:
- ドキュメントを開いたら、プラグインを起動します（**Plugins ＞ Development ＞ Yunatype**。2 回目からは Ctrl+Alt+P / ⌘+Option+P）。ボタンはありません。ドキュメントで使っているフォントのうち、Yunatype が持っているものが自動で有効になります。プラグインを閉じると外れます。
- プラグインを開いているドキュメントには、選んだフォントをドロップして文字を置けます。

### Affinity
Affinity（3.2 以降）は、プラグインのインストールが要りません。

1. Affinity の設定で **MCP サーバーを有効**にします。
2. Affinity を再起動します。

これで、Affinity で開いているドキュメントのフォントが自動で有効になります（ドキュメントを閉じると外れます）。状態は Yunatype の**環境設定 ＞ 連携**で確かめられます。

## 📥 インストールの詳細

### Windows
1. [Releases](https://github.com/yunatype/yunatype/releases/latest) から最新の `Yunatype_<バージョン>_x64-setup.exe` をダウンロードします。
2. ダウンロードしたファイルを実行します。言語を選び、使用許諾を読んで同意すると、インストールが始まります。

### macOS
1. [Releases](https://github.com/yunatype/yunatype/releases/latest) から最新の `.dmg` をダウンロードします（Apple Silicon・Intel の両方で動きます）。
2. 開いた窓で `Yunatype` を `Applications` へドラッグします。

### 「Windows によって PC が保護されました」と表示されたとき
このアプリにはコード署名（有料の証明書）を付けていないため、初めて実行するときに Windows の SmartScreen が警告を出すことがあります。

1. 警告の画面で**「詳細情報」**をクリックします。
2. **「実行」**をクリックします。

ブラウザが「ダウンロードしたファイルは、一般的にダウンロードされていません」と表示した場合も、「保存」または「保持する」を選んで続けてください。

### 「開発元を検証できません」と表示されたとき（macOS）
このアプリには Apple の署名・公証を付けていないため、初めて開くときに macOS が警告を出すことがあります。

1. 警告の画面で**「完了」**（または「OK」）を押して、いったん閉じます。
2. **システム設定 ＞ プライバシーとセキュリティ**を開き、下の方の Yunatype の項目で**「このまま開く」**を押します。
3. もう一度出る確認で**「開く」**を押します。

### アンインストール
- Windows: 「設定 ＞ アプリ」から Yunatype を削除します。
- macOS: `Applications` の Yunatype をゴミ箱に入れます。

どちらも、フォントのファイル本体は削除されません。

## 🛟 困ったとき

- **有効にしたのに、Photoshop などにフォントが出ない**: クイックルック（Space）の**「詳細メタデータ」タブの一番下の「診断」**を使います。Windows がフォントを認識しているか、同名のフォントが重複していないか、などを調べます。Windows が認識しているのに出ない場合は、Photoshop を再起動すると出ることがあります。
- **フォントを取り込んだのに、一覧が空**: 取り込みが終わると自動で表示されます。表示されないときは、Yunatype をいったん終了（タスクトレイのアイコンからも終了できます）して、もう一度起動してください。
- **NAS のフォントが読み込めない**: ネットワークの接続と、フォルダにアクセスできるかを確認してください。
- **Figma の黄色い警告が消えない**: Figma のファイルタブで Ctrl+R（再読み込み）を 1 回押してください。
- **Figma のプラグインに「アプリ未起動」と出る**: Yunatype を起動してください（約 2 秒で接続中に切り替わります）。
- **Windows で、同じ名前のフォントの片方しか使えない**: Windows は、ファミリー名・太さ・斜体が同じフォントを 1 つしか見せません。フォントを制作ソフトにドロップしたときに、そのことをお知らせします。使いたい方だけを有効にしてください。

## 🔒 プライバシー

Yunatype は、あなたの名前・メールアドレス・手持ちのフォントの名前・ファイルの場所を収集・送信しません。設定とデータは、あなたのパソコンの中（Windows は `%LOCALAPPDATA%\Yunatype`、macOS は `~/Library/Application Support/Yunatype`）にだけ保存されます。Adobe の拡張機能、Figma のプラグイン、Affinity との通信は、あなたのパソコンの中だけで行われます。

ただし、次の場合はインターネットに接続します。

- **利用統計**（どの機能がよく使われているかを知るため）: 1 日に 1 回、次のものだけを送ります。使った機能の回数（検索・クイックルック・比較）、エラーとクラッシュの回数、フォントの数と日本語・簡体字のフォントの有無（おおまかな区分）、Yunatype のバージョン、OS、表示言語、国（OS の地域設定から）、この端末をつなぐ無作為の ID、初めて使った日、Google Fonts の公開名簿にあるファミリー名の利用回数。手持ちのフォントの名前、ファイルの場所、個人を特定する情報は送りません。通信の際、あなたの IP アドレスがサーバーに届きます（サーバーには保存しません）。
  - EU・英国・スイス・韓国・ブラジルなど、同意を先に取る地域（地域が分からないときも同じ）では、**同意するまで送りません**。それ以外の地域では、お知らせのカードを表示した翌日から送ります。
  - **環境設定 ＞ プライバシー**で、いつでもオフにできます。送る内容の確認、端末 ID のリセット、サーバー上のデータの削除も、そこでできます。
- **Google Fonts を有効にしたとき**（既定はオフ）: 名簿の取得（Google の `fonts.google.com`、GitHub の `google/fonts`）と、見本の表示・ダウンロード（`fonts.googleapis.com`、`raw.githubusercontent.com`）のために、それらのサーバーに接続します。アクセスの数は、間隔と同時接続数を絞って抑えています。あなたのフォントの情報は送りません（見本に使う文字は送ります）。オフにすると接続しません。
- **更新の確認**のため、起動時に GitHub へ最新バージョンを問い合わせます（このとき、あなたの IP アドレスが GitHub に伝わります）。**環境設定 ＞ 一般 ＞ ソフトウェアアップデートの「起動時に更新を確認する」**でオフにできます。
