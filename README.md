# Yunatype

数万件のフォントを、**インストールせずに**、素早く探して、必要なときだけ使えるようにする、Windows と macOS 用の**無料**のフォントマネージャーです。

フォントを、OS のフォントフォルダへコピーせずに、使う間だけ有効にします（動的アクティベーション）。Photoshop や Illustrator のフォント一覧が、散らかりません。

> **English**: Yunatype is a free font manager for Windows (10/11, 64-bit) and macOS (11 or later). It lets you browse and search tens of thousands of fonts and activate them only while you need them, without installing them. It works with Photoshop, Illustrator, Figma and Affinity. Free for personal and commercial use. Download the installer from [Releases](https://github.com/yunatype/yunatype/releases/latest). See [LICENSE](LICENSE) for the terms (Japanese is authoritative; an English reference translation is included).

**対応**: Windows 10 / 11（64 ビット）、macOS 11（Big Sur）以降（Apple Silicon・Intel の両対応）。

## ダウンロードとインストール

### Windows
1. [Releases](https://github.com/yunatype/yunatype/releases/latest) から、最新の `Yunatype_<バージョン>_x64-setup.exe` をダウンロードします。
2. ダウンロードしたファイルを、実行します。言語（日本語 / English / 简体中文 / 繁體中文 / 한국어 / Deutsch / Français / Español / Italiano / Português / Nederlands / Dansk / Polski / Русский）を選び、使用許諾を読んで、同意すると、インストールが始まります。

### macOS
1. [Releases](https://github.com/yunatype/yunatype/releases/latest) から、最新の `.dmg` をダウンロードします（Apple Silicon・Intel の両方で動きます）。
2. 開いた窓で、`Yunatype` を `Applications` へドラッグします。

### 共通
起動したら、**環境設定 ＞ フォントフォルダ**で、フォントを置いているフォルダ（ローカル、NAS、外付けディスク）を追加します。取り込みが終わると、一覧に表示されます。

### 「Windows によって PC が保護されました」と表示されたとき
このアプリには、コード署名（有料の証明書）を付けていないため、初めて実行するときに、Windows の SmartScreen が警告を出すことがあります。

1. 警告の画面で、**「詳細情報」**をクリックします。
2. **「実行」**をクリックします。

ブラウザが「ダウンロードしたファイルは、一般的にダウンロードされていません」と表示した場合も、「保存」または「保持する」を選んで、続けてください。

### 「開発元を検証できません」と表示されたとき（macOS）
このアプリには、Apple の署名・公証を付けていないため、初めて開くときに、macOS が警告を出すことがあります。

1. 警告の画面で、**「完了」**（または「OK」）を押して、いったん閉じます。
2. **システム設定 ＞ プライバシーとセキュリティ**を開き、下の方の Yunatype の項目で、**「このまま開く」**を押します。
3. もう一度出る確認で、**「開く」**を押します。

### アンインストール
- Windows: 「設定 ＞ アプリ」から、Yunatype を削除します。
- macOS: `Applications` の Yunatype を、ゴミ箱に入れます。

どちらも、フォントのファイル本体は、削除されません。

## 主な機能

- **インストール不要の動的アクティベーション**: 起動中だけ、必要なフォントをシステム全体に即時ロードします。アプリの終了時や、異常終了からの復帰時には、有効化したフォントを自動で回収します。
- **超高速のライブラリ管理**: ファミリー単位の表示、ウェイト別の一覧、高速な検索。数万件の一覧を、キーの押しっぱなしでも止まらずにスクロールできます。
- **NAS / LAN 上のフォルダに対応**: フォルダを並列に探索し、進捗（件数・取り込み中のフォント名）を表示します。キャンセルもできます。設定からフォルダを外すと、配下のフォントも、ライブラリから外れます（フォントのファイル本体は、削除しません）。
- **クイックルック（Space）とグリフマップ**: 大きな書体見本、ファミリー全ウェイト、詳細メタデータ、収録文字の一覧。プレビューは、フォントの実際の見え方を、そのまま表示します。
- **フォントの比較**: 一覧で複数選んで Space（4 件まで）。クイックルックを、複数のフォントで横に並べます。見本の文字・サイズ・タブは、全フォントに同時に効きます。
- **診断**: 有効にしたのに、Photoshop などに出ないフォントの原因を探ります（ファイルの状態、Windows の認識、同名フォントの重複）。
- **Adobe（Photoshop / Illustrator）・Figma・Affinity の連携**: 書類で使われているフォントを検知し、自動で有効化します。書類を閉じると、そのフォントだけを自動で解除します。
- **カードを制作ソフトに落として、文字を置く**: 一覧のカードを、Photoshop・Illustrator・Figma・Affinity の書類へドラッグ＆ドロップすると、そのフォントで例文を置きます。複数選んで落とすと、縦に並べて置きます（最大 10 個）。
- **検索**: 名前・PostScript 名・英語名・メーカー・デザイナー・タグなどで探せます。候補から選んだメーカーやスタイルは、その項目だけで絞り込みます。
- **Google Fonts を、同じ一覧に混ぜられます**（任意。既定はオフ）: 環境設定でオンにすると、Google Fonts の名簿のフォントが、手持ちのフォントと同じ一覧に並びます。ダウンロードする前に、見本を見られます。有効にした（Enter）ときに、そのファミリーだけをダウンロードします。手持ちに同じフォントがあれば、手持ちが優先されます。
- **言語フィルター**: 日本語、簡体字、韓国語、ラテン文字、キリル文字、ギリシャ文字などで、フォントを絞り込めます（複数選択できます）。
- **14 言語の画面**（日本語 / English / 简体中文 / 繁體中文 / 한국어 / Deutsch / Français / Español / Italiano / Português / Nederlands / Dansk / Polski / Русский）と **5 つのテーマ**。インストーラー、Adobe の拡張パネル、Figma のプラグイン、タスクトレイのメニューも、各言語に対応しています。見本の例文も、各言語のものを選べます。

## Photoshop などで使う

1. Yunatype でフォントを選んで、**Enter** で有効化します。
2. **C キー**で、Photoshop のフォント欄で検索できる名前（ファミリー名 ＋ スタイル。例: 「A-OTF ららぽっぷ Std R」）をコピーします。
3. Photoshop のフォント欄（検索）に貼り付けます。

- Photoshop は、画面に出ている表示名で探します。PostScript 名や英語名では、ヒットしません。PostScript 名が必要なときは、**Shift+C** です。

### 書類を開くと、自動で有効化する（Adobe 連携）
Photoshop / Illustrator で書類を開くと、使われているフォントを検知して、自動で有効化します（書類を閉じると、そのフォントだけを自動で解除します）。

- Windows の Photoshop・Illustrator: インストーラーが、拡張機能を自動で入れます。
- Mac の Illustrator: 最初に 1 回、Yunatype の**環境設定 ＞ 連携**で「拡張機能を再インストール / 最新化」を押して、拡張機能を入れます。
- どちらも、パネルを開かなくても、裏で動きます。つながっているかを見たいときは、メニューの「**ウィンドウ ＞ エクステンション ＞ Yunatype**」を開きます。
- Mac の Photoshop: パネルは要りません。初めて連携するときに、**システム設定 ＞ プライバシーとセキュリティ ＞ オートメーション**で、Yunatype から Adobe Photoshop への操作を許可してください。

### カードを落として、文字を置く
一覧のカードを、Photoshop や Illustrator の書類の上へドラッグ＆ドロップすると、落とした場所に、そのフォントで例文を置きます。まだ有効になっていないフォントは、自動で有効にします。取り消し（Ctrl+Z / ⌘+Z）で、置いた文字を消せます。

## Figma と連携する

Figma Desktop のプラグイン「Yunatype」を使います。**最初に 1 回だけ**、次の設定をします。

1. Yunatype の**環境設定 ＞ 連携**を開き、「Figma Desktop プラグイン連携」の欄で、**「プラグインのフォルダを開く」**を押します（`manifest.json` が選択された状態で開きます）。
2. Figma Desktop で、**Plugins ＞ Development ＞ Import plugin from manifest...** を選び、1 のフォルダの `manifest.json` を選びます（欄の「manifest.json のパスをコピー」で、パスを貼り付けることもできます）。
3. 環境設定の**「外部連携 API トークン」**の「コピー」を押し、Figma のプラグインの、トークンの入力欄に貼り付けて、保存します。

使い方:
- 書類を開いたら、プラグインを起動します（**Plugins ＞ Development ＞ Yunatype**。2 回目からは Ctrl+Alt+P / ⌘+Option+P）。ボタンはありません。書類で使っているフォントのうち、Yunatype が持っているものが、自動で有効になります。プラグインを閉じると、外れます。
- プラグインを開いている書類には、カードを落として、文字を置けます。

## Affinity と連携する

Affinity（3.2 以降）は、プラグインのインストールが要りません。

1. Affinity の設定で、**MCP サーバーを有効**にします。
2. Affinity を再起動します。

これで、Affinity で開いている書類のフォントが、自動で有効になります（書類を閉じると、外れます）。Windows では、カードを Affinity の書類へ落として、文字を置くこともできます。状態は、Yunatype の**環境設定 ＞ 連携**で確かめられます。

## 困ったとき

- **有効にしたのに、Photoshop などに、フォントが出ない**: クイックルック（Space）の**「詳細」タブの一番下の「診断」**を使います。Windows が、フォントを認識しているか、同名のフォントが重複していないか、などを調べます。Windows が認識しているのに、出ない場合は、Photoshop を再起動すると出ることがあります。
- **フォントを取り込んだのに、一覧が空**: 取り込みが終わると、自動で表示されます。表示されないときは、Yunatype を、いったん終了（タスクトレイのアイコンからも終了できます）して、もう一度起動してください。
- **NAS のフォントが、読み込めない**: ネットワークの接続を確認してください。変更のないファイルは、再解析されません（2 回目以降は速く終わります）。
- **Figma の黄色い警告が消えない**: Figma のファイルタブで、Ctrl+R（再読み込み）を 1 回押してください。
- **Windows で、同じ名前のフォントの片方しか使えない**: Windows は、ファミリー名・太さ・斜体が同じフォントを、1 つしか見せません。カードを落としたときに、そのことをお知らせします。使いたい方だけを有効にしてください。
- **Figma のプラグインに「アプリ未起動」と出る**: Yunatype を起動してください（約 2 秒で、接続中に切り替わります）。

## プライバシー

Yunatype は、あなたの名前・メールアドレス・手持ちのフォントの名前・ファイルの場所を、収集・送信しません。設定とデータは、あなたのパソコンの中（Windows は `%LOCALAPPDATA%\Yunatype`、Mac は `~/Library/Application Support/Yunatype`）にだけ、保存されます。Adobe の拡張機能、Figma のプラグイン、Affinity との通信は、あなたのパソコンの中だけで行われます。

ただし、次の場合は、インターネットに接続します。

- **利用統計**（どの機能がよく使われているかを知るため）: 1 日に 1 回、次のものだけを送ります。使った機能の回数（検索・クイックルック・比較）、エラーとクラッシュの回数、フォントの数と日本語・簡体字のフォントの有無（おおまかな区分）、Yunatype のバージョン、OS、表示言語、国（OS の地域設定から）、この端末をつなぐ無作為の ID、初めて使った日、Google Fonts の公開名簿にあるファミリー名の利用回数。手持ちのフォントの名前、ファイルの場所、個人を特定する情報は、送りません。通信の際、あなたの IP アドレスが、サーバーに届きます（サーバーには、保存しません）。
  - EU・英国・スイス・韓国・ブラジルなど、同意を先に取る地域（地域が分からないときも同じ）では、**同意するまで、送りません**。それ以外の地域では、お知らせのカードを表示した、翌日から送ります。
  - **環境設定 ＞ プライバシー**で、いつでも、オフにできます。送る内容の確認、端末 ID のリセット、サーバー上のデータの削除も、そこでできます。

- **Google Fonts を有効にしたとき**（既定はオフ）: 名簿の取得（Google の `fonts.google.com`、GitHub の `google/fonts`）と、見本の表示・ダウンロード（`fonts.googleapis.com`、`raw.githubusercontent.com`）のために、それらのサーバーに接続します。アクセスの数は、間隔と同時接続数を絞って、抑えています。あなたのフォントの情報は、送りません（見本に使う文字は、送ります）。オフにすると、接続しません。
- **更新の確認**のため、起動時に、GitHub に、最新バージョンを問い合わせます（このとき、あなたの IP アドレスが GitHub に伝わります）。**環境設定 ＞ 一般 ＞ ソフトウェアアップデートの「起動時に更新を確認する」**で、オフにできます。
